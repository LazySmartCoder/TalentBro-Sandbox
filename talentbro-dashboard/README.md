# TalentBro Dashboard

Build TalentBro, a premium placement-management dashboard for college TPOs with a clean modern SaaS design.
Include sidebar pages: Overview, Students, Companies, Placement Drives, AI Interviews, Reports, Notifications, Settings.
Add KPI cards, placement graphs, department analytics, placement funnel, active drives, schedules, and AI interview insights.
Include searchable student/company tables, profiles, drive creation, candidate pipeline, AI scores/evaluations, and placement reports.
Use consistent realistic Indian college mock data and make navigation, filters, charts, tables, modals, and actions interactive. black and white only
